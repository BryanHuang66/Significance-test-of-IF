# IF Significance Tests

This directory is for the simulation experiments in the information-flow significance test paper. 

> **Note:** The core package is hosted at **https://github.com/NCOADS/LK_info_flow**. Please ensure it is cloned and accessible as described below.

## Structure

```text
IF Significance Tests/
  src/
  walkthrough.ipynb
  README.md
  requirements.txt

```

## Setup

```bash
git clone [https://github.com/NCOADS/LK_info_flow](https://github.com/NCOADS/LK_info_flow)
export LK_INFO_FLOW_ROOT=/path/to/LK_info_flow
pip install -r requirements.txt

```

## Usage

To reproduce the results, simply run `walkthrough.ipynb`.
